# Rust 热路径优化 A/B

同机相邻配对，轮次交替先后顺序；各变体使用同一个客户端二进制。
每个进程预热 5 秒，计时 8 秒，加在途请求排空。
每个场景单独重新测基线，不使用前一天或前一份报告的吞吐作分母。
所有响应逐字节校验，STATS验证完整命令后置过滤器计数。
